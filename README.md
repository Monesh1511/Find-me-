# 📱 Find Me – College Lost & Found Application

## 📌 Project Description

**Find Me** is a mobile-based Lost & Found application designed specifically for college campuses. The application provides a centralized digital platform where students can report **lost** and **found** items, browse existing listings, and directly contact the concerned person.

Traditional methods such as notice boards or informal WhatsApp groups are unorganized and inefficient. **Find Me** addresses this problem by offering a structured, searchable, and easy-to-use solution that significantly improves the chances of recovering lost belongings within the campus.

The application is built using **Flutter** for the frontend and **Flask** for the backend, following a **3-tier architecture** with **MySQL** as the database.

---

## 🎯 Objectives

- Provide a centralized platform for reporting lost and found items  
- Reduce the time taken to recover lost belongings  
- Improve communication between the finder and the owner  
- Replace unstructured manual methods with a digital solution  
- Build a scalable and maintainable full-stack application
